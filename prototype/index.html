Color Shift: iOS design as a web prototype

Left: the Figma "iOS exploration" design, built in the browser, with taps that work. Right: the Figma frame for the screen you're on. Tap the score pill, the ⋯ and swap buttons, a color, the + button, and ‹ ›. Glass is a browser approximation of Apple's Liquid Glass. Icons stand in for SF Symbols. Photos are live from Unsplash via the local helper (server.py). Each pair uses the photo's Unsplash color as the background and the same hue pushed to WCAG 4.5 for the text, a simpler stand-in for Matt's palette extraction.
